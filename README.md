# 럭키 6/45 번호 생성기

역대 로또 6/45 1등 당첨 조합을 빼고 번호를 뽑을 수 있는 무료 번호 생성기입니다.

- 역대 1등 조합 제외 기능 켜기/끄기
- 1~5게임 생성, 고정수·제외수 지정
- 게임별로 가장 비슷했던 과거 회차 표시
- 카메라로 로또 용지 QR을 비추면 실시간으로 당첨·낙첨 확인 (여러 장 연속 확인)
- 내 번호 보관함: 뽑은 번호·QR 용지를 저장하면 추첨 뒤 등수 자동 표시
- 판매 마감까지 남은 시간, 실수령액(세후) 계산기
- 1등 명당 지도: 262회부터의 1등 판매점, 지역별·내 주변 보기 (지도: OpenStreetMap)
- 페이지를 열 때마다 최신 회차 당첨번호 자동 반영 (데이터: [smok95/lotto](https://github.com/smok95/lotto))

동행복권 및 복권위원회와 관련 없는 비공식 개인 사이트입니다. 어떤 조합이든 1등 확률은 똑같이 8,145,060분의 1입니다.
